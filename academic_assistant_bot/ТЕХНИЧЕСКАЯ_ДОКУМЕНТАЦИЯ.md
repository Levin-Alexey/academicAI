### 3. Модели данных (`database/models.py`)
```python
class User(Base):
    __tablename__ = "users"
    
    id = Column(BigInteger, primary_key=True)
    username = Column(String(255), nullable=True)
    first_name = Column(String(255), nullable=True)
    last_name = Column(String(255), nullable=True)
    created_at = Column(DateTime, default=datetime.utcnow)

class UserSettings(Base):
    __tablename__ = "user_settings"
    
    id = Column(Integer, primary_key=True)
    user_id = Column(BigInteger, ForeignKey("users.id"))
    model_name = Column(String(255), default="deepseek/deepseek-chat-v3-0324:free")
    created_at = Column(DateTime, default=datetime.utcnow)
    updated_at = Column(DateTime, default=datetime.utcnow)

class Deal(Base):
    __tablename__ = "deals"
    
    id = Column(Integer, primary_key=True)
    user_id = Column(BigInteger, ForeignKey("users.id"))
    deal_type = Column(String(255), nullable=False)
    content = Column(Text, nullable=False)
    created_at = Column(DateTime, default=datetime.utcnow)
```

## 💭 Система контекста

### Принцип работы
1. **Сохранение:** Каждое сообщение пользователя и ответ бота сохраняются в Redis
2. **Загрузка:** При новом запросе контекст загружается и добавляется к системному промпту
3. **Ограничение:** Максимум 10 сообщений на пользователя
4. **TTL:** Контекст автоматически удаляется через 1 час

### Формат данных
```json
[
    {"role": "user", "content": "Напиши курсовую работу"},
    {"role": "assistant", "content": "Конечно! Вот структура курсовой работы..."},
    {"role": "user", "content": "Теперь напиши введение"},
    {"role": "assistant", "content": "Введение к курсовой работе..."}
]
```

### Redis ключи
- `context_{user_id}` - Контекст пользователя
- TTL: 3600 секунд (1 час)

## 🚀 Развертывание

### 1. Подготовка сервера
```bash
# Обновление системы
apt update && apt upgrade -y

# Установка Python
apt install python3.10 python3.10-venv python3-pip -y

# Установка PostgreSQL
apt install postgresql postgresql-contrib -y

# Установка Redis
apt install redis-server -y
```

### 2. Настройка базы данных
```bash
sudo -u postgres psql
CREATE DATABASE academic_bot;
CREATE USER bot_user WITH PASSWORD 'secure_password';
GRANT ALL PRIVILEGES ON DATABASE academic_bot TO bot_user;
```

### 3. Настройка Redis
```bash
# Редактировать /etc/redis/redis.conf
bind 0.0.0.0
requirepass RedisBot2025!
```

### 4. Развертывание приложения
```bash
# Создание директории
mkdir -p /opt/academic_assistant_bot
cd /opt/academic_assistant_bot

# Создание виртуального окружения
python3.10 -m venv venv
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Настройка переменных окружения
cp .env.example .env
nano .env
```

### 5. Создание systemd сервиса
```bash
# /etc/systemd/system/academic-assistant-bot.service
[Unit]
Description=Academic Assistant Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/academic_assistant_bot
Environment=PATH=/opt/academic_assistant_bot/venv/bin
ExecStart=/opt/academic_assistant_bot/venv/bin/python main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

### 6. Запуск сервиса
```bash
systemctl daemon-reload
systemctl enable academic-assistant-bot.service
systemctl start academic-assistant-bot.service
```

## 📈 Масштабирование

### Горизонтальное масштабирование
1. **Несколько инстансов бота:** Каждый инстанс может обрабатывать свой набор пользователей
2. **Балансировка нагрузки:** Распределение запросов между инстансами
3. **Репликация базы данных:** Чтение с реплик, запись в мастер

### Вертикальное масштабирование
1. **Увеличение ресурсов сервера:** CPU, RAM, диск
2. **Оптимизация Redis:** Увеличение памяти, настройка политик удаления
3. **Настройка PostgreSQL:** Увеличение shared_buffers, work_mem

### Кэширование
```python
# Кэширование пользовательских настроек
async def get_user_model_cached(user_id: int) -> str:
    cache_key = f"user_model_{user_id}"
    cached = await redis.get(cache_key)
    
    if cached:
        return cached
    
    model = await user_service.get_user_model(user_id)
    await redis.setex(cache_key, 3600, model)
    return model
```

## 🐛 Отладка

### Типичные проблемы

#### 1. Конфликт ботов
```
TelegramConflictError: terminated by other getUpdates request
```
**Решение:** Убедитесь, что запущен только один экземпляр бота

#### 2. Ошибки базы данных
```
sqlalchemy.exc.OperationalError: connection to server failed
```
**Решение:** Проверьте соединение с PostgreSQL

#### 3. Ошибки Redis
```
redis.exceptions.ConnectionError: Error connecting to Redis
```
**Решение:** Проверьте статус Redis и настройки подключения

#### 4. Ошибки OpenRouter API
```
aiohttp.ClientError: OpenRouter API error
```
**Решение:** Проверьте API ключ и лимиты
