# 📚 Academic Assistant Bot - Полная документация

## 🎯 Что это такое?

**Academic Assistant Bot** — это умный Telegram-бот, который помогает студентам и исследователям создавать качественные академические работы. Бот использует современные технологии искусственного интеллекта для написания курсовых, дипломных работ, рефератов и других научных текстов.

---

## 🏗️ Как устроен бот?

### 💻 Техническая основа
Бот построен на современных технологиях:
- **Telegram API** - для общения с пользователями
- **4 модели искусственного интеллекта** - для создания текстов
- **База данных PostgreSQL** - для хранения пользователей и настроек
- **Redis** - для запоминания контекста разговора
- **Сервер Linux** - для круглосуточной работы

### 🔐 Система безопасности
- **Закрытый доступ** - работает только с разрешенными пользователями
- **Контроль администратора** - можно добавлять и удалять пользователей
- **Защищенные данные** - все настройки хранятся в зашифрованном виде

## 📱 Как пользоваться ботом

### 🎛️ Главное меню

После запуска `/start` вы увидите кнопки:

**📝 Новая работа**
- Начать создание академического текста
- Получить помощь с существующей работой
- Продолжить предыдущий проект

**🗑️ Очистить контекст**
- Удалить историю разговора
- Начать с чистого листа
- Освободить память бота

**👥 Управление пользователями** *(только для администраторов)*
- Добавить новых пользователей
- Посмотреть список доверенных людей
- Удалить доступ у пользователей

**⚙️ Настройки**
- Выбрать модель искусственного интеллекта
- Сохранить персональные предпочтения

**ℹ️ Помощь**
- Инструкция по использованию
- Описание возможностей
- Контакты для поддержки

### 🎯 Процесс работы

1. **Начните новую работу**
   - Нажмите "📝 Новая работа"
   - Опишите что вам нужно

2. **Опишите задание**
   ```
   Примеры запросов:
   "Создай структуру курсовой работы на тему 'Искусственный интеллект в медицине'"
   "Напиши введение к дипломной работе по экономике"
   "Подготовь главу 2 по теме 'Анализ рынка'"
   ```

3. **Получите результат**
   - Бот создаст текст с помощью ИИ
   - Вы получите файл .txt для скачивания
   - Плюс краткий предварительный просмотр

4. **Продолжите работу**
   - Задавайте уточняющие вопросы
   - Просите доработать разделы
   - Бот помнит контекст разговора

## 💾 Умная память бота

### 🧠 Как работает контекст:

**Запоминание разговора:**
- Бот помнит **последние 30 сообщений**
- История сохраняется **1 час** после последнего сообщения
- Можно работать над проектом несколько дней

**Преимущества:**
- Связность между частями работы
- Учет ваших предпочтений
- Продолжение с того места где остановились
- Исправления и дополнения в контексте

**Управление памятью:**
- Кнопка "🗑️ Очистить контекст" для начала заново
- Автоматическая очистка через час неактивности
- Информация о количестве сохраненных сообщений

## 👨‍💼 Управление пользователями

### 🔑 Для администраторов:

**Просмотр пользователей** 📋
- Список всех доверенных пользователей
- Информация: имя, username, Telegram ID
- Дата добавления каждого пользователя

**Добавление новых пользователей** ➕
- Ввод Telegram ID пользователя
- Автоматическое получение имени и username
- Проверка на дубликаты
- Валидация корректности ID

**Удаление пользователей** ❌
- Деактивация доступа
- Сохранение истории в базе данных
- Возможность восстановления доступа

### 🆔 Как найти Telegram ID:
1. Напишите боту @userinfobot
2. Перешлите ему любое сообщение пользователя
3. Получите информацию с ID
4. Или воспользуйтесь @getmyid_bot

## 🚨 Типичные ситуации и решения

### ❓ Частые вопросы:

**"Бот не отвечает"**
- Проверьте подключение к интернету
- Убедитесь что у вас есть доступ к боту
- Попробуйте команду /start

**"Получил ошибку при генерации"**
- Попробуйте переформулировать запрос
- Выберите другую модель ИИ в настройках
- Очистите контекст и начните заново

**"Текст не соответствует теме"**
- Уточните требования более детально
- Укажите специфические требования
- Используйте контекст предыдущих сообщений

**"Нужно добавить пользователя"**
- Обратитесь к администратору бота
- Предоставьте Telegram ID пользователя
- Дождитесь подтверждения добавления

### ⚡ Советы по эффективному использованию:

1. **Детальные запросы**
   ```
   ❌ "Напиши про ИИ"
   ✅ "Напиши введение к курсовой работе на тему 'Применение 
       искусственного интеллекта в диагностике заболеваний' 
       объемом 2-3 страницы"
   ```

2. **Поэтапная работа**
   - Сначала попросите структуру работы
   - Затем пишите по разделам
   - Используйте контекст для связности

3. **Уточнения и исправления**
   - Не стесняйтесь просить доработки
   - Указывайте конкретные замечания
   - Используйте фразы "дополни", "исправь", "расширь"
