## 🤖 Что это за бот и для чего он нужен

**Академический помощник** - это умный Telegram-бот, который помогает студентам и учащимся с написанием различных академических работ. Бот использует современные технологии искусственного интеллекта для создания качественных текстов.

### 🎯 Главные задачи бота:
- **Помощь в написании курсовых работ** - создание структуры, написание глав и разделов
- **Подготовка дипломных проектов** - от планирования до написания полного текста
- **Создание рефератов и эссе** - быстрое и качественное написание небольших работ
- **Структурирование материала** - организация информации в логическом порядке
- **Проверка и улучшение текста** - редактирование и оптимизация готового материала

### 🔍 Особенности:
- **Память разговора** - бот помнит всю историю вашего общения и может продолжать работу над проектом
- **Разные модели ИИ** - возможность выбора наиболее подходящей модели для вашей задачи
- **Файловый вывод** - результаты сохраняются в удобные .txt файлы
- **Русский язык** - бот полностью адаптирован для русскоязычных пользователей

## 🚀 Как начать работу с ботом

### Шаг 1: Найти бота
1. Откройте Telegram
2. В поиске введите: `@akademforwork_bot`
3. Нажмите на бота из результатов поиска

### Шаг 2: Запустить бота
1. Нажмите кнопку **"ЗАПУСТИТЬ"** или **"START"**
2. Или отправьте команду `/start`

### Шаг 3: Ознакомиться с главным меню
После запуска вы увидите приветственное сообщение и главное меню с четырьмя кнопками:
- 📝 **Новая работа**
- 🗑️ **Очистить контекст**
- ⚙️ **Настройки**
- ℹ️ **Помощь**

## 📋 Подробное описание функций

### 📝 Новая работа
**Для чего:** Основная функция для создания любых академических текстов

**Как работает:**
1. Нажимаете кнопку "📝 Новая работа"
2. Бот переходит в режим ожидания вашего запроса
3. Вы описываете, что вам нужно
4. Бот анализирует запрос и создает текст
5. Результат отправляется в виде текстового файла

**Что можно запросить:**
- "Создай структуру курсовой работы на тему 'Искусственный интеллект в образовании'"
- "Напиши введение к дипломной работе по программированию"
- "Подготовь реферат на тему 'История России в 18 веке'"
- "Создай заключение для курсовой по экономике"

### 🗑️ Очистить контекст
**Для чего:** Стирает всю историю общения с ботом

**Когда использовать:**
- Когда заканчиваете работу над одним проектом и начинаете новый
- Если хотите, чтобы бот "забыл" предыдущие разговоры
- При переходе к совершенно другой теме

**Как работает:**
1. Нажимаете кнопку "🗑️ Очистить контекст"
2. Бот показывает информацию о том, сколько сообщений будет удалено
3. Подтверждаете очистку
4. История общения полностью стирается

### ⚙️ Настройки
**Для чего:** Выбор модели ИИ для генерации текста

**Доступные модели:**
- 🧠 **DeepSeek** - быстрая и эффективная модель
- 🤖 **Claude Sonnet 4** - отличная для академических текстов
- 💡 **Gemini 2.0 Flash** - модель от Google с высокой скоростью
- 🌟 **OpenAI GPT-4.1 Mini** - компактная версия GPT-4

**Как выбрать модель:**
1. Нажмите "⚙️ Настройки"
2. Выберите нужную модель из списка
3. Текущая модель будет отмечена галочкой ✅
4. Нажмите "⬅️ Назад" для возврата в главное меню

**Для чего:** Получение справочной информации

## 📖 Пошаговые инструкции

### Как создать курсовую работу

#### Шаг 1: Создание структуры
1. Нажмите "📝 Новая работа"
2. Отправьте запрос: "Создай подробную структуру курсовой работы на тему '[ваша тема]' для [ваша специальность]"
3. Получите файл со структурой
4. Изучите предложенную структуру

#### Шаг 2: Написание введения
1. Снова нажмите "📝 Новая работа" (или продолжите в том же диалоге)
2. Отправьте: "Напиши введение к курсовой работе на основе созданной структуры"
3. Получите файл с введением

#### Шаг 3: Написание основной части
1. Отправьте: "Напиши первую главу курсовой работы"
2. Получите файл с первой главой
3. Повторите для остальных глав: "Напиши вторую главу курсовой работы"

#### Шаг 4: Создание заключения
1. Отправьте: "Создай заключение для курсовой работы, подводящее итоги всех глав"
2. Получите файл с заключением

#### Шаг 5: Список литературы
1. Отправьте: "Создай список литературы по теме курсовой работы"
2. Получите файл со списком источников

### Как создать реферат

#### Шаг 1: Планирование
1. Нажмите "📝 Новая работа"
2. Отправьте: "Создай план реферата на тему '[ваша тема]' объемом [количество страниц] страниц"

#### Шаг 2: Написание
1. Отправьте: "Напиши полный текст реферата по созданному плану"
2. Получите готовый реферат в файле

#### Шаг 3: Дополнение (при необходимости)
1. Отправьте: "Добавь больше информации о [конкретный аспект темы]"
2. Получите дополненную версию

### Как улучшить готовый текст

#### Вариант 1: Редактирование
1. Скопируйте ваш текст
2. Нажмите "📝 Новая работа"
3. Отправьте: "Отредактируй и улучши этот текст: [вставьте ваш текст]"

#### Вариант 2: Проверка стиля
1. Отправьте: "Проверь этот текст на соответствие академическому стилю и исправь ошибки: [ваш текст]"

#### Вариант 3: Расширение
1. Отправьте: "Дополни этот текст более подробной информацией: [ваш текст]"

## ❓ Часто задаваемые вопросы

### 1. **Бот не отвечает на мои сообщения**
**Ответ:** Убедитесь, что вы нажали кнопку "📝 Новая работа" перед отправкой запроса. Бот отвечает только в режиме создания работы.

### 2. **Как сохранить результат работы?**
**Ответ:** Все результаты автоматически сохраняются в .txt файлы, которые бот отправляет вам в Telegram. Просто нажмите на файл и выберите "Скачать".

### 3. **Можно ли продолжить работу над проектом позже?**
**Ответ:** Да! Бот запоминает всю историю общения. Вы можете вернуться к проекту через несколько дней, и бот будет помнить все детали.

### 4. **Как очистить историю общения?**
**Ответ:** Нажмите кнопку "🗑️ Очистить контекст" в главном меню.

### 5. **Какую модель выбрать для моей задачи?**
**Ответ:** 
- Для дипломных работ: Claude Sonnet 4
- Для быстрых задач: DeepSeek
- Для творческих работ: OpenAI GPT-4.1 Mini
- Для универсальных задач: Gemini 2.0 Flash

### 6. **Можно ли использовать бота для проверки готовых текстов?**
**Ответ:** Да! Отправьте запрос вида: "Проверь и улучши этот текст: [ваш текст]"

### 7. **Сколько времени занимает генерация текста?**
**Ответ:** Обычно от 10 секунд до 2 минут, в зависимости от сложности запроса и выбранной модели.

### 8. **Можно ли создать работу на определенное количество страниц?**
**Ответ:** Да! Укажите в запросе желаемый объем: "Создай курсовую работу на 20 страниц"

### 9. **Бот может работать с техническими специальностями?**
**Ответ:** Да! Бот хорошо справляется с техническими темами, программированием, математикой, физикой и другими точными науками.

### 10. **Как сформулировать запрос для лучшего результата?**
**Ответ:** Будьте конкретными:
- Указывайте тему работы
- Упоминайте вашу специальность
- Указывайте желаемый объем
- Описывайте особые требования

## 🔧 Решение проблем

### Проблема: Бот не отвечает
**Решение:**
1. Убедитесь, что нажали "📝 Новая работа"
2. Проверьте подключение к интернету
3. Попробуйте отправить команду `/start`
4. Если не помогает, перезапустите Telegram

### Проблема: Получаю ошибку при генерации
**Решение:**
1. Попробуйте изменить модель ИИ в настройках
2. Упростите формулировку запроса
3. Разбейте сложный запрос на несколько простых
4. Очистите контекст и попробуйте снова

### Проблема: Результат не соответствует ожиданиям
**Решение:**
1. Сформулируйте более конкретный запрос
2. Добавьте дополнительные детали и требования
3. Попробуйте другую модель ИИ
4. Попросите бота улучшить результат

### Проблема: Файл не скачивается
**Решение:**
1. Проверьте место на устройстве
2. Попробуйте скачать позже
3. Перезапустите Telegram
4. Скопируйте текст из файла вручную

### Проблема: Бот "забыл" предыдущие сообщения
**Решение:**
1. Проверьте, не нажимали ли вы "🗑️ Очистить контекст"
2. Контекст автоматически очищается через час неактивности
3. Кратко напомните боту о предыдущих договоренностях
